每次重启都需要注意

因为目前使用的是 Cloudflare Quick Tunnel，每次启动可能生成不同的公网地址。

所以需要：

  1. 打开 index.html。
  2. 搜索旧的 Cloudflare 地址。
  3. 将四处 API 地址全部替换成这次生成的新地址：
    • /login
    • /register
    • /me
