微积分第二章笔记

2.4 函数的微分

一、 基础知识

  1. 可微与可导的关系：函数 f(x) 可微就可导（互为充要条件），微分记作 dy。
  2. 微分的定义式：在点 x₀ 处的微分 dy = f’(x₀) · Δx （Δx 为自变量的增量）。
  3. 一般微分公式：dy = f’(x) · dx （因为规定自变量的微分 dx = Δx）。
  4. 微分与增量的关系：Δy - dy = o(Δx)，即函数的增量与微分的差是 Δx 的高阶无穷小。
  5. 等价无穷小关系：当 f(x) 在 x₀ 处的导数不等于0时，dy 与 Δy 是等价无穷小量（即 dy ~ Δy）。
  6. 一阶微分的形式不变性：无论 x 是自变量还是中间变量（如 x = g(t)），一阶微分的形式始终为 dy = f’(x) dx。
  7. 近似公式与近似值：f(x) ≈ f(x₀) + f’(x₀) · (x - x₀)，一般令 x₀ = 0 且 x 很小时，f(x) ≈ f(0) + f’(0) · x。

二、 一般题型

1、求函数的微分： dy = f’(x) · dx

2.5 高阶导数与高阶微分

一、 基础知识

  1. 高阶微分的定义式：dny=f(n)(x)⋅dxnd^n y = f^{(n)}(x) \cdot dx^n。对于 nn 阶微分，直接套用此公式。

    • 注意：dxndx^n 为 (dx)n(dx)^n（即 dxdx 的 nn 次方），而非 d(xn)d(x^n)。

  2. 特殊函数的 nn 阶导数公式（必须熟记）：

      1. 指数函数：(ax)(n)=ax⋅(ln⁡a)n(a^x)^{(n)} = a^x \cdot (\ln a)^n，特别地 (ex)(n)=ex(e^x)^{(n)} = e^x。
    • (2) 正弦函数：(sin⁡x)(n)=sin⁡(x+n⋅π2)(\sin x)^{(n)} = \sin\left(x + n \cdot \frac{\pi}{2}\right)。
    • (3) 余弦函数：(cos⁡x)(n)=cos⁡(x+n⋅π2)(\cos x)^{(n)} = \cos\left(x + n \cdot \frac{\pi}{2}\right)，一般地 (cos⁡ax)(n)=an⋅cos⁡(ax+n⋅π2)(\cos ax)^{(n)} = a^n \cdot \cos\left(ax + n \cdot \frac{\pi}{2}\right)。
    • (4) 幂函数（m≥nm \ge n）：(xm)(n)=m(m−1)⋯(m−n+1)xm−n(x^m)^{(n)} = m(m-1)\cdots(m-n+1)x^{m-n}。
    • (5) 对数与分式：[ln⁡(1+x)](n)=(−1)n−1(n−1)!(1+x)n[\ln(1+x)]^{(n)} = \frac{(-1)^{n-1}(n-1)!}{(1+x)^n}；(1x+1)(n)=(−1)nn!(x+1)n+1\left(\frac{1}{x+1}\right)^{(n)} = \frac{(-1)^n n!}{(x+1)^{n+1}}。
    • (6) 平移分式：(1x±a)(n)=(−1)nn!(x±a)n+1\left(\frac{1}{x \pm a}\right)^{(n)} = \frac{(-1)^n n!}{(x \pm a)^{n+1}}。
    • 注意：若形如 x−1x-1（即 a<0a<0），则先提出 (−1)(-1) 转化为标准形式再套公式。

二、 一般题型

1、分段函数求高阶导：

  • 核心原则：必须分段验证，高阶导数可能不可导。
  • 题型示例：已知 f(x)={x4sin⁡1x,x≠00,x=0f(x) = \begin{cases} x^4 \sin \frac{1}{x}, & x \neq 0 \\ 0, & x = 0 \end{cases}，求 x=0x=0 处的最高阶导数。
  • 解法：f′(0)f'(0) 及 f″(0)f''(0) 只能由导数定义计算（即 f(n)(0)=lim⁡x→0f(n−1)(x)−f(n−1)(0)xf^{(n)}(0) = \lim_{x \to 0} \frac{f^{(n-1)}(x) - f^{(n-1)}(0)}{x}），当 x≠0x \neq 0 时使用求导法则，若求导后极限震荡不存在，则无法继续求导。

2、有理分式求 nn 阶导：

  • 题型示例：求 y=x2x2−2x−3y = \frac{x^2}{x^2 - 2x - 3} 的 nn 阶导数。
  • 解法：先进行多项式除法化为 1+2x+3x2−2x−31 + \frac{2x+3}{x^2-2x-3}，再利用待定系数法进行部分分式展开（拆分为 Ax−3+Bx+1\frac{A}{x-3} + \frac{B}{x+1}），最后转化为标准形式，套用公式 (6)。

2.6 隐函数、参数方程与极坐标求导

一、 基础知识

  1. 隐函数求导原则：把 yy 视作内部的一个复合函数，求导时 y→y′y \to y'（即对 yy 正常求导，当作 xx 来看待，求导后要再乘一个 y′y'）。
  2. 参数方程求导公式：设 {x=φ(t)y=ψ(t)\begin{cases} x = \varphi(t) \\ y = \psi(t) \end{cases}
    • 一阶导：dydx=ψ′(t)φ′(t)\frac{dy}{dx} = \frac{\psi'(t)}{\varphi'(t)}
    • 二阶导：d2ydx2=(ψ′(t)φ′(t))′⋅1φ′(t)\frac{d^2y}{dx^2} = \left( \frac{\psi'(t)}{\varphi'(t)} \right)' \cdot \frac{1}{\varphi'(t)}（注意：前面是对 tt 求导，千万不能忘记最后乘的 1φ′(t)\frac{1}{\varphi'(t)}）。
  3. 极坐标方程转化公式：{x=rcos⁡θy=rsin⁡θ\begin{cases} x = r \cos \theta \\ y = r \sin \theta \end{cases}。

二、 一般题型

1、隐函数求导：

  • 一阶导：方程两边同时对 xx 求导，提取 y′y' 并解出。例题：由 exy+sin⁡(x+y)=0e^{xy} + \sin(x+y) = 0 求导得 exy(y+xy′)+cos⁡(x+y)(1+y′)=0e^{xy}(y + xy') + \cos(x+y)(1 + y') = 0，化简即可得 y′y'。
  • 二阶导：在原有的一阶导 y′=⋯y' = \cdots 基础下，直接对 y′y' 的右侧再求导，之后将一阶导数 y′y' 的表达式代入化简。

2、参数方程求导：

  • 直接套用基础公式，二阶导牢记乘以 1φ′(t)\frac{1}{\varphi'(t)}。

3、极坐标方程求导：

  • 解法步骤：对于极坐标方程（如 r=asin⁡bθr = a \sin b\theta）：
    1. 转化为直角坐标（代入 x=rcos⁡θ,y=rsin⁡θx = r\cos\theta, y = r\sin\theta）；
    2. 转化为参数方程（此时 θ\theta 就是参数方程里的 tt）；
    3. 套用参数方程求导法求解。
