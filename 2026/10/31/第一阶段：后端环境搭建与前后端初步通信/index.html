3. 什么是 Web？

Web 是 World Wide Web 的缩写，中文通常称为万维网。

可以将 Web 理解为一个通过网络访问网站和相关服务的体系。

例如，用户通过浏览器打开洛蒂亚网站：

浏览器显示的地图、文字、图片和按钮，都是 Web 应用的一部分。

4. 什么是后端开发？

后端开发是负责程序后台处理工作的开发领域。

例如：

  • 处理用户注册和登录；
  • 保存和读取用户数据；
  • 处理用户提交的故事；
  • 执行业务逻辑；
  • 管理用户权限。

后端开发并不只有 Web 后端开发。

Web 后端开发是后端开发的一种，主要为网站和 Web 应用提供后台服务。

例如洛蒂亚未来的注册、投稿和审核功能，都需要 Web 后端提供支持。

5. 什么是 Web 框架？

Web 框架（Web Framework）是一套预先准备好的开发工具、基础结构和规则，用于帮助开发者构建 Web 应用。

如果不使用 Web 框架，开发者需要自己处理许多基础工作，例如：

  • 接收浏览器发送的请求；
  • 判断请求访问的地址；
  • 读取请求中的数据；
  • 执行对应的处理逻辑；
  • 将处理结果返回给请求方；
  • 处理各种错误。

Web 框架提供了现成的功能，使开发者不必从零开始完成这些工作。

可以理解为：

  • Python 提供编程语言本身的基础能力。
  • Web 框架提供开发 Web 应用所需要的工具和结构。
  • 开发者在框架的基础上编写具体业务功能。

6. 什么是 API？

API 全称是 Application Programming Interface，中文为应用程序编程接口。

API 不是某种软件拓展，也不是某一个具体的开发框架，而是一种接口概念。

API 的核心作用是规定不同程序之间如何进行沟通。

以洛蒂亚用户注册功能为例：

用户在网页中填写用户名、密码和邮箱，然后点击注册。

前端需要将这些数据发送给后端，而前后端必须事先约定沟通方式。

例如：

项目 约定
接口地址 /register
请求方法 POST
提交的数据 用户名、密码、邮箱
后端处理 创建用户账户
返回结果 注册成功或失败

这套约定就是一个 API 接口。

API 的价值在于：

  • 前端只需要按照约定发送请求，不需要了解后端内部如何创建账户。
  • 后端只需要按照约定接收数据和返回结果，不需要了解前端的页面设计。
  • 两个程序可以在不了解对方内部实现细节的情况下进行交互。

7. FastAPI 是什么？

FastAPI 是一个使用 Python 开发的 Web 框架。

它主要帮助开发者：

  • 创建 API 接口；
  • 接收前端发送的数据；
  • 执行后端处理逻辑；
  • 将处理结果返回给前端。

需要区分：

名称 本质 作用
Web 网站及其网络服务所处的领域 提供整体运行环境
后端开发 一个开发领域 处理程序后台业务
Web 后端开发 后端开发的一种 为网站提供后台服务
API 一种接口概念 规定程序之间如何沟通
Web 框架 一类开发工具 提供 Web 应用的基础结构
FastAPI 具体的 Python Web 框架 帮助开发者编写后端、创建 API

洛蒂亚使用 FastAPI，是为了编写网站后端，并通过 API 实现前后端之间的数据交换。

3. 什么是 Uvicorn？

Uvicorn 是一种 ASGI 服务器软件。

它的核心作用是运行 FastAPI 应用，并负责接收、传递和返回网络请求。

这里需要区分服务器的两种含义：

  • 服务器硬件：提供计算、存储和网络能力的计算机。
  • 服务器软件：运行在计算机上的程序，负责接收请求并提供服务。

Uvicorn 属于服务器软件，而不是一台服务器计算机。

2. 什么是源（Origin）？

一个源由三个部分组成：

  1. 协议，例如 http。
  2. 主机名，例如 127.0.0.1。
  3. 端口号，例如 5500。

只要其中任意一项不同，就属于不同的源。

例如：

两者的端口号不同，因此属于不同的源。

3. 什么是 CORS？

CORS 全称是 Cross-Origin Resource Sharing，中文叫作跨域资源共享。

它是一种浏览器与服务器协作的机制，用来控制网页是否可以访问不同源的资源。

浏览器存在同源策略，因此前端网页跨域访问后端时，需要后端通过 CORS 响应头表明是否允许这种访问。
