顶部图片替换

模块三：顶部背景图片替换与网站部署

一、修改 Hexo 主题样式的基本原则

Hexo 项目中，修改主题样式时，需要区分源文件和生成文件。

文件或目录 作用
themes/landscape/source/css/style.styl 主题样式源文件，修改样式时主要编辑这里
themes/landscape/layout/_partial/header.ejs 主题顶部结构文件，包含顶部横幅 banner 的 HTML 结构
themes/landscape/source/css/images/ 存放主题样式所需的图片资源
public/css/style.css Hexo 生成的 CSS 文件
public/css/images/ 生成后供网站使用的图片目录

核心原则：修改源文件，再重新生成网站。

public 目录中的文件是生成结果，重新执行 hexo clean 和 hexo g 后会重新生成。因此，不应直接把 public/css/style.css 当作长期修改的源文件。

六、部署失败时的 SSH 连接问题

本次部署过程中还遇到过 GitHub SSH 连接超时的问题。

当时的情况是：

  • 通过 SSH 默认端口 22 连接 GitHub 时超时。
  • 测试 ssh.github.com 的 443 端口时可以连接。
  • 将 SSH 配置改为使用 GitHub 的 443 端口后，执行 ssh -T git@github.com 成功认证，之后 Hexo 部署成功。

七、本模块总结

本次完成了以下内容：

  1. 认识了 Landscape 主题中 header.ejs、style.styl 和 style.css 的不同作用。
  2. 确认了 #banner 是顶部横幅元素的选择器。
  3. 将顶部背景图片从 banner.jpg 替换为 back.jpg。
  4. 学会了检查图片生成结果和 CSS 中的图片路径。
  5. 掌握了 hexo clean、hexo g 和 hexo d 的基本用途。
