微积分第一章笔记

微积分第一章：极限与连续

一、 易考辨析类知识点

1. 极限的本质与基础定义

  • 极限前提：极限存在的前提必为极限为常数（适用于所有定理，推广至拆分时的需求）。
  • 独立性：函数极限 (\lim_{x\to x_0} f(x)) 的值与 (f(x_0)) 无关，且 (f(x)) 可在 (x=x_0) 上无定义（(x \neq x_0)）。
  • 数列特征：在极限领域中有无限个项、之外有有限个项（无论范围多少）。在收敛数列中任意增减有限项，本性不改。数列极限一般只研究逼近于 (\infty) 时。
  • 收敛与有界：收敛数列必有界，有界数列不一定收敛。
  • 函数分类：基本初等函数（幂、指、对、三、反三、常）与初等函数（有限次四则运算与复合运算）。初等函数的极限值 = 在该点的函数值。
  • 反函数图像：(y=f(x)) 与反函数 (x=g(y)) 图像相同（(x=f^{-1}(y) \Leftrightarrow y=f(x) \Leftrightarrow x=f(y))）。
  • 特殊函数：Dirichlet（狄利克雷）函数无最小正周期。取整函数 ([x] \le x < [x]+1)。
  • 极坐标切换：((r, \theta) \Rightarrow (x, y)) 有 (x = r\cos\theta, y = r\sin\theta)；((x, y) \Rightarrow r = \sqrt{x^2+y^2}, \cos\theta = \frac{x}{r})。
  • 反三角函数：(f(x)=\arctan x) 图像（有界性）。(x\to+\infty) 时 (\lim \arctan x = \frac{\pi}{2})，且 (\arctan x + \arctan\frac{1}{x} = \frac{\pi}{2})。

2. 无穷小、无穷大与阶数

  • 无穷小本质：以0为极限的变量。若 (\lim f(x)=A)，则无穷小量为 (f(x)-A=\alpha)（变量 (\alpha) 为函数）。等价形式：(\lim f(x)=A \Leftrightarrow f(x)=A+o(1))。
  • 无穷大与无穷小：互为倒数（不为0）。
  • (o(1)) 运算：有限个 (o(1)) 的 (+,-,\times) 均为 (o(1))；(\div) 不一定，未定式。
  • 有界量乘无穷小：有界量乘无穷小量等于无穷小量也可以认为是0（典型：(x\sin\frac{1}{x}=0)）。
  • 振荡形注意：无穷小量要注意振荡形，可能在趋近过程中为0。
  • 零乘大陷阱：(\lim x_n y_n = 0)，不一定有 (x_n) 为无穷小（反例为0）。
  • 阶数判断：通过这一项的等价无穷小量判断它的次数，进而判断它的阶数。计算时必须注意趋近的到底是哪里，从而抓大头或抓小头。
  • 高阶、低阶、同阶：(\lim \frac{f}{g}=0)（(f)为高阶，(g)为低阶）；(\lim \frac{f}{g}=1)（(f \sim g) 等价无穷小）；(\lim \frac{f}{g}=C)（(f)为(k)阶无穷小量）。

3. 连续与间断

  • 探讨有界：探讨一个函数在什么范围内有界，可以对这个范围的边界进行求极限，看看是不是常数或者是无穷。
  • 连续的前提：①在 (x_0) 附近有定义；②(\lim f(x)) 存在；③(\lim f(x)=f(x_0)) 函数值=极限值。连续 (\Leftrightarrow) 左右均连续。
  • 间断点分类：
    • 两边均有极限且极限相等，是可去间断点（只是挖掉了这个点，在这个点上没有定义，但是极限有，分母为零可能是这种）。
    • 左右极限不相等，则是跳跃间断点。
    • 至少有一边的极限为无穷，则是无穷间断点（彻底化简之后，常数比0大概率是）。
    • 震荡的话，则是震荡间断点（三角函数可能是这种）。
    • 【经典例题】 求 (f(x) = \frac{x}{e^{1/x} - 1}) 的间断点。
    • 【解析】 (x=0) 是间断点。(\lim_{x\to 0^+} f(x) = 0)；(\lim_{x\to 0^-} f(x) = 0)。左右极限存在且相等，故 (x=0) 为可去间断点。

二、 基础定理

1. 极限性质与运算法则

  • 极限的运算法则：当且仅当极限为常数下成立。推广至拆分时的需求。
  • 保号与保序性：(\lim a_n=A, \lim b_n=B)。① (A>B)，则 (\exists N, n>N, a_n>b_n, a_n>B, A>b_n)。② (a_n \ge b_n)，则 (A \ge B)。
  • 无穷小比例推论：若 (\lim \frac{f(x)}{g(x)}=C \ (C \neq 0))，若 (\lim g(x)=0)，则必有 (\lim f(x)=0)。
  • 绝对值极限：(\lim a_n=A \Rightarrow \lim |a_n|=|A|)。
  • 左右极限：函数极限存在条件为左右极限均存在且相等（(\lim_{x\to x_0^+} = \lim_{x\to x_0^-})）。同样适用局部有界与保号性。四则运算法则同样要求为常数极限。
  • 复合函数的极限：(\lim_{x\to x_0} g(x)=u_0)，(\lim_{u\to u_0} f(u)=A)，且 (x \neq x_0, g(x) \neq u_0)，则 (\lim_{x\to x_0} f(g(x))=A)。对于 (u_0, x_0^+, x_0^-) 均成立。

2. 极限存在判定准则

  • 海涅定理（函数极限存在准则）：(\lim f(x)=A \Leftrightarrow x) 的去心邻域内，且收敛于 (x_0) 的 ({x_n}) 均有极限。（等同数列极限准则，一般用于证明极限不存在）。
    • 【经典例题】 证明 (\lim_{x\to 0} \sin\frac{1}{x}) 不存在。
    • 【解析】 取 (x_n = \frac{1}{2n\pi} \to 0)，(\sin\frac{1}{x_n} = 0 \to 0)；取 (y_n = \frac{1}{2n\pi + \pi/2} \to 0)，(\sin\frac{1}{y_n} = 1 \to 1)。两个子列极限不同，故原极限不存在。
  • 子列收敛定理：({a_n}) 收敛 (\Rightarrow) 所有子列均收敛。所有子列收敛 (\Rightarrow {a_n}) 收敛。({a_n}) 收敛 (\Leftrightarrow {a_{2n}}) 与 ({a_{2n-1}}) 均收敛。
  • 夹逼法则：取等与否均可。
  • 数列单调 + 有一确界 (\Rightarrow) 收敛 = 有极限 (\Rightarrow) 可以不求极限。

3. 闭区间连续函数性质

  • 零点存在定理：(f(x)) 属于 ([A,B]) 的连续闭区间，(f(A)f(B)<0)，则存在 (\xi \in [A,B]) 使 (f(\xi)=0)。此类题基本都涉及构造新函数（大的 (F(x)) 等于小的 (f(x)) 加上或减去某个值）。
    • 【经典例题】 证明方程 (x = e^{x-2}) 在 ((0,2)) 内至少有一个实根。
    • 【解析】 构造函数 (F(x) = x - e^{x-2})。(F(0) = -e^{-2} < 0)，(F(2) = 2 - e^0 = 1 > 0)。(F(x)) 连续，由零点定理得证。
  • 反函数连续性定理：(f(x)) 在 (I) 上单调且连续，值域为 (J)，则其反函数在 (J) 上单调且连续。

三、 极限的求解类型（方法大全）

1. 抓大头

  • 对于项目多并且类型不同的可以进行抓大头。
  • (x) 趋近于无穷时：(A^X > X^\alpha > \log_a X)（(X) 远小于 (X^\alpha)）。
  • (x) 趋近于0时：(X) 远大于 (X^2)。
  • 若分母相同、分子繁杂，可不动分子动分母；对分母解化时不能改变任一量级（指数）。大相同 (\Rightarrow) 此时可以抓大头。
  • 【经典例题】 (\lim_{x\to +\infty} \frac{\sqrt{x^2+1}}{x})。
  • 【解析】 (x\to +\infty) 抓大头，分子等价于 (x)，分母为 (x)，故极限为 (1)。

2. 洛必达法则

  • (\frac{0}{0}) 或 (\frac{\infty}{\infty}) 型可用洛必达。分数形式别忘了大胆用。
  • 对于 (\sin X, \cos X)，在 (X) 趋近于无穷时不能用洛必达法则，但是可以抓大头。

3. 夹逼法则

  • 古希腊哲学中多项求法的情况，类似有规律求和类，方法是通过做所有相变最大或变最小来找到上下边缘。取等与否均可。
  • 放缩时不论对分子和分母变化，都不应该改变任意一部分的量级（即指数）。大相同 (\Rightarrow) 可以抓大头。
  • 特殊类型：求极限 (N \to \infty) 时，((A_1^N + A_2^N + \dots + A_M^N)^{1/N})，这个结果的极限是 (A_1) 到 (A_M) 中的最大的项。
  • 【经典例题】 (\lim_{n\to\infty} \left( \frac{n}{n^2+1} + \frac{n}{n^2+2} + \dots + \frac{n}{n^2+n} \right))。
  • 【解析】 放缩分母：(\frac{n \cdot n}{n^2+n} \le S_n \le \frac{n \cdot n}{n^2+1})。两端极限均为 1，故 (S_n \to 1)。

4. 分子有理化

  • 根号与根号相减，必分子有理化。
  • 【经典例题】 (\lim_{x\to +\infty} (\sqrt{x^2+x} - x))。
  • 【解析】 分子有理化：(\frac{x}{\sqrt{x^2+x} + x})。上下同除以 (x)，极限为 (\frac{1}{1+1} = \frac{1}{2})。

5. 通分

  • (0 \times \infty) 型化简为 (\frac{0}{0}) 或 (\frac{\infty}{\infty})；(\infty - \infty) 型变通分，提早通分。

6. 有界量

  • 碰到反三角函数时，要思考利用其有界。
  • 有界量乘无穷小量 = 无穷小量 = 0。
  • 【经典例题】 (\lim_{x\to 0} x^2 \sin\frac{1}{x})。
  • 【解析】 (|\sin\frac{1}{x}| \le 1) 为有界量，(x^2 \to 0) 为无穷小，极限为 0。

7. 求未知数（双圆梯形已知极限求未知数）

  • 已知极限的情况下，求函数中的两个常量的值。方法：①分子有理化或通分；②提取出来的 (X)（最高次幂）。
  • 【经典例题】 已知 (\lim_{x\to 0} \frac{\sqrt{1+ax^2}-1}{x^2} = b)，求 (a,b) 的关系。
  • 【解析】 分子有理化或等价无穷小。原式 (= \lim_{x\to 0} \frac{\frac{1}{2}ax^2}{x^2} = \frac{a}{2} = b)，故 (a = 2b)。

8. 幂指代换

  • 无穷的零次方、0的零次方、1的无穷次方都转化为1的YN次方（即 (e^{\lim v\ln u})）。
  • 指数有未知量时，要进行底数代换。
  • 【经典例题】 (\lim_{x\to 0} \left(\frac{\sin x}{x}\right)^{1/x^2})。
  • 【解析】 属 (1^\infty) 型。原式 (= \exp(\lim_{x\to 0} \frac{\ln(\sin x/x)}{x^2}))。利用泰勒 (\sin x - x \sim -x^3/6)，指数极限为 (-1/6)，结果为 (e^{-1/6})。

9. 两指数相减

  • 遇到两指数相减的情况，提取公因式或进行转化。

10. 提出后一项

  • 遇到多项相加减，提取后一项/最高次项进行化简。

11. 拆分

  • 对于分数类型，拆分分子及拆分时需不需要加 (1-1) 或 (+X-X)，根本判断是拆分能否符合极限的四则运算（极限必须是常数）。
  • 符合条件时积极拆分，尝试加 (1-1) 或加 (X-X)。
  • 对于某一小部分的乘法和除法，要积极使用等价无穷小替换。

12. 其他关键操作与防坑点

  • 多项式同除最高项：(X \to \pm\infty) 时相加减，将所有项同时除以最高项。
  • 对数函数：一定要加一减一构造等价无穷小替换。
  • 换元：通过换元实现等价无穷小替换。
  • 直接代入：只要不是 (X \to \infty) 且不在定义域内，(X \to c) 时要大胆代入常数。
  • 防坑点：尽量不要分数套分数，容易有不可进行等价无穷小替换的情况。用定义域找反例。
  • 递推数列：证明收敛时同时证明单调且同侧有界（常用数学归纳法）。计算极限时，将 (X_N) 和 (X_{N+1}) 的极限都用 (X) 表达，解方程。
    • 【经典例题】 (x_1=\sqrt{2}, x_{n+1}=\sqrt{2+x_n})，求极限。
    • 【解析】 数学归纳法证 (x_n<2) 且有界，单调递增。设极限为 (A)，解 (A=\sqrt{2+A})，得 (A=2)。
  • 等价无穷小选择：对于 (a^X-1 \sim X\ln a) 与 ((1+X)^\alpha-1 \sim \alpha X)，实际要仔细判断用哪一种，有些题中 (\ln) 形式不好化解。

13. 必背工具库

（1）等价无穷小（均 (X \to 0) 方向）

  • (\sin X \sim X)、(\tan X \sim X)、(\arcsin X \sim X)、(\arctan X \sim X)、(e^X-1 \sim X)、(\ln(1+X) \sim X)。
  • (1-\cos X \sim \frac{1}{2}X^2)、(a^X-1 \sim X\ln a)、((1+X)^\alpha-1 \sim \alpha X)、(\log_a(1+X) \sim \frac{X}{\ln a})。
  • (\tan X - X \sim \frac{1}{3}X^3)、(\tan X - \sin X \sim \frac{1}{2}X^3)、(X-\sin X \sim \frac{1}{6}X^3)。

（2）重要极限与结论

  • (N \to \infty) 时：(N^{1/N}=1)、(A^{1/N}=1)、((1+1/N)^N=e)。
  • 极限值：(\lim_{x\to+\infty} \frac{x}{a^x}=0)、(\lim_{x\to+\infty} \frac{\log_a x}{x}=0)。
  • 级数求和：(\frac{1}{1^2}+\frac{1}{2^2}+\dots=\frac{\pi^2}{6})。
  • 裂项相消：(\frac{1}{1\cdot 2}+\frac{1}{2\cdot 3}+\dots+\frac{1}{n(n+1)}=1)。

（3）求导公式

  • ((\arctan X)’ = \frac{1}{1+X^2})
  • ((\tan X)’ = 1+\tan^2 X = \sec^2 X = \frac{1}{\cos^2 X})
  • ((\cot X)’ = -\csc^2 X)，且 (\cot X = \frac{\cos X}{\sin X})
  • ((\sin^2 X)’ = \sin 2X = 2\sin X\cos X)
  • ((\arccos X)’ = -\frac{1}{\sqrt{1-X^2}})

（4）泰勒公式/经典例题补充

  • (\lim_{x\to 0} \frac{\cos x - e^{-x^2/2}}{x^4})。
  • 【解析】 (\cos x = 1-\frac{1}{2}x^2+\frac{1}{24}x^4+o(x^4))，(e^{-x^2/2} = 1-\frac{1}{2}x^2+\frac{1}{8}x^4+o(x^4))。分子相减得 (-\frac{1}{12}x^4)，结果 (-\frac{1}{12})。
