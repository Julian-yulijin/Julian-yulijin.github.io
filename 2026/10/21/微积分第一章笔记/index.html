微积分第一章笔记

微积分第一章：极限与连续（全量题型与高价值例题版）

一、易考辨析类知识点

1. 极限的本质与基础定义

  • 极限前提： 极限存在的前提必为极限为常数（适用于所有定理，推广至拆分时的需求）。
  • 独立性： 函数极限 (\lim_{x\to x_0} f(x)) 的值与 (f(x_0)) 无关，且 (f(x)) 可在 (x=x_0) 上无定义（(x\neq x_0)）。
  • 数列特征： 在极限领域中有无限个项、之外有有限个项（无论范围多少）。在收敛数列中任意增减有限项，本性不改。数列极限一般只研究逼近于 (\infty) 时。
  • 收敛与有界： 收敛数列必有界，有界数列不一定收敛。
  • 函数分类： 基本初等函数（幂、指、对、三、反三、常）与初等函数（有限次四则运算与复合运算）。初等函数的极限值 = 在该点的函数值。
  • 反函数图像： (y=f(x)) 与反函数 (x=g(y)) 图像相同：
    [
    x=f^{-1}(y)\Leftrightarrow y=f(x)\Leftrightarrow x=f(y)
    ]
  • 特殊函数： Dirichlet（狄利克雷）函数无最小正周期。取整函数满足：
    [
    [x]\le x<[x]+1
    ]
  • 极坐标切换：
    • 极坐标 ((r,\theta)) 转直角坐标 ((x,y))：
      [
      x=r\cos\theta,\qquad y=r\sin\theta
      ]
    • 直角坐标 ((x,y)) 转极坐标：
      [
      r=\sqrt{x^2+y^2},\qquad \cos\theta=\frac{x}{r}
      ]
  • 反三角函数： (f(x)=\arctan x) 图像具有有界性。当 (x\to+\infty) 时：
    [
    \lim_{x\to+\infty}\arctan x=\frac{\pi}{2}
    ]
    且：
    [
    \arctan x+\arctan\frac{1}{x}=\frac{\pi}{2}
    ]

2. 无穷小、无穷大与阶数

  • 无穷小本质： 以 0 为极限的变量。若 (\lim f(x)=A)，则无穷小量为 (f(x)-A=\alpha)（变量 (\alpha) 为函数）。
  • 等价形式：
    [
    \lim f(x)=A\Leftrightarrow f(x)=A+o(1)
    ]
  • 无穷大与无穷小： 互为倒数（不为 0）。
  • (o(1)) 运算： 有限个 (o(1)) 的加、减、乘均为 (o(1))；除法不一定，属于未定式。
  • 有界量乘无穷小： 有界量乘无穷小量等于无穷小量，也可以认为是 0（典型：(x\sin\frac{1}{x}=0)）。
  • 振荡形注意： 无穷小量要注意振荡形，可能在趋近过程中为 0。
  • 零乘大陷阱： (\lim x_ny_n=0)，不一定有 (x_n) 为无穷小（反例为 0）。
  • 阶数判断： 通过这一项的等价无穷小量判断它的次数，进而判断它的阶数。计算时必须注意趋近的到底是哪里，从而抓大头或抓小头。
  • 高阶、低阶、同阶：
    • (\lim\frac{f}{g}=0)：(f) 为高阶无穷小，(g) 为低阶无穷小。
    • (\lim\frac{f}{g}=1)：(f\sim g)，二者为等价无穷小。
    • (\lim\frac{f}{g}=C)：若 (C\neq 0)，则二者为同阶无穷小。

3. 连续与间断

  • 探讨有界： 探讨一个函数在什么范围内有界，可以对这个范围的边界进行求极限，看看是不是常数或者是无穷。

  • 连续的前提：

    1. 在 (x_0) 附近有定义。
    2. (\lim_{x\to x_0}f(x)) 存在。
    3. (\lim_{x\to x_0}f(x)=f(x_0))，即函数值等于极限值。

    连续 (\Leftrightarrow) 左右均连续。

  • 间断点分类：

    • 可去间断点： 两边均有极限且极限相等，只是挖掉了这个点，在这个点上没有定义，但是极限存在。分母为零可能是这种情况。
    • 跳跃间断点： 左右极限不相等。
    • 无穷间断点： 至少有一边的极限为无穷（彻底化简之后，常数比 0 大概率是）。
    • 振荡间断点： 极限振荡，三角函数可能出现这种情况。

经典例题：求间断点

求：
[
f(x)=\frac{x}{e^{1/x}-1}
]
的间断点。

解析：

(x=0) 是间断点。

当 (x\to0^+) 时，(e^{1/x}\to+\infty)，因此：
[
\lim_{x\to0^+}f(x)=0
]

当 (x\to0^-) 时，(e^{1/x}\to0)，因此：
[
\lim_{x\to0^-}f(x)=0
]

左右极限存在且相等，故 (x=0) 为可去间断点。

二、基础定理

1. 极限性质与运算法则

  • 极限的运算法则： 当且仅当极限为常数下成立。推广至拆分时的需求。
  • 保号与保序性： 若 (\lim a_n=A)，(\lim b_n=B)，则：
    1. 若 (A>B)，则存在 (N)，当 (n>N) 时，有 (a_n>b_n)、(a_n>B)、(A>b_n)。
    2. 若 (a_n\ge b_n)，则 (A\ge B)。
  • 无穷小比例推论： 若
    [
    \lim\frac{f(x)}{g(x)}=C,\qquad C\neq0
    ]
    且 (\lim g(x)=0)，则必有 (\lim f(x)=0)。
  • 绝对值极限：
    [
    \lim a_n=A\Rightarrow\lim|a_n|=|A|
    ]
  • 左右极限： 函数极限存在的条件为左右极限均存在且相等：
    [
    \lim_{x\to x_0^+}f(x)=\lim_{x\to x_0^-}f(x)
    ]
    同样适用于局部有界与保号性。四则运算法则同样要求为常数极限。
  • 复合函数的极限： 若
    [
    \lim_{x\to x_0}g(x)=u_0,\qquad
    \lim_{u\to u_0}f(u)=A
    ]
    且 (x\neq x_0)、(g(x)\neq u_0)，则：
    [
    \lim_{x\to x_0}f(g(x))=A
    ]
    对于 (u_0)、(x_0^+)、(x_0^-) 均成立。

2. 极限存在判定准则

（1）海涅定理

函数极限存在准则：

[
\lim_{x\to x_0}f(x)=A
]

当且仅当对去心邻域内任意收敛于 (x_0) 的数列 ({x_n})，相应函数值数列均收敛于 (A)。

等同数列极限准则，一般用于证明极限不存在。

经典例题：证明
[
\lim_{x\to0}\sin\frac{1}{x}
]
不存在。

解析：

取：
[
x_n=\frac{1}{2n\pi}\to0
]

则：
[
\sin\frac{1}{x_n}=0\to0
]

再取：
[
y_n=\frac{1}{2n\pi+\pi/2}\to0
]

则：
[
\sin\frac{1}{y_n}=1\to1
]

两个数列对应的函数值极限不同，故原极限不存在。

（2）子列收敛定理

  • ({a_n}) 收敛 (\Rightarrow) 所有子列均收敛。
  • 所有子列收敛 (\Rightarrow) ({a_n}) 收敛。
  • ({a_n}) 收敛 (\Leftrightarrow) ({a_{2n}}) 与 ({a_{2n-1}}) 均收敛。

（3）夹逼法则

取等与否均可。

（4）单调有界定理

数列单调且有界（存在一确界）(\Rightarrow) 收敛，即有极限 (\Rightarrow) 可以不求极限。

3. 闭区间连续函数性质

（1）零点存在定理

若 (f(x)) 在闭区间 ([A,B]) 上连续，且：
[
f(A)f(B)<0
]

则存在 (\xi\in[A,B])，使得：
[
f(\xi)=0
]

此类题基本都涉及构造新函数（大的 (F(x)) 等于小的 (f(x)) 加上或减去某个值）。

经典例题：证明方程
[
x=e^{x-2}
]
在 ((0,2)) 内至少有一个实根。

解析：

构造函数：
[
F(x)=x-e^{x-2}
]

计算端点：
[
F(0)=-e^{-2}<0
]
[
F(2)=2-e^0=1>0
]

(F(x)) 连续，由零点存在定理得证。

（2）反函数连续性定理

若 (f(x)) 在区间 (I) 上单调且连续，值域为 (J)，则其反函数在 (J) 上单调且连续。

三、极限的求解类型（方法大全）

1. 抓大头

  • 对于项目多并且类型不同的，可以进行抓大头。
  • (x) 趋近于无穷时，增长速度通常满足：
    [
    A^x>x^\alpha>\log_a x
    ]
    （在相应参数满足条件时，(x) 远小于 (x^\alpha)）。
  • (x) 趋近于 0 时，(x) 远大于 (x^2)。
  • 若分母相同、分子繁杂，可不动分子、动分母；对分母化简时不能改变任一量级（指数）。大相同 (\Rightarrow) 此时可以抓大头。

经典例题：
[
\lim_{x\to+\infty}\frac{\sqrt{x^2+1}}{x}
]

解析：

(x\to+\infty) 时抓大头，分子等价于 (x)，分母为 (x)，故极限为：
[
1
]

2. 洛必达法则

  • (\frac00) 或 (\frac{\infty}{\infty}) 型可用洛必达法则。分数形式别忘了大胆用。
  • 对于 (\sin X)、(\cos X)，在 (X) 趋近于无穷时不能直接用洛必达法则，但是可以抓大头。

3. 夹逼法则（假币法则 / 古希腊哲学）

  • 古希腊哲学中多项求法的情况，类似有规律求和类，方法是通过做所有项相变最大或变最小来找到上下边缘。取等与否均可。
  • 放缩时，不论对分子和分母变化，都不应该改变任意一部分的量级（即指数）。大相同 (\Rightarrow) 可以抓大头。
  • 特殊类型： 求极限 (N\to\infty) 时：
    [
    \left(A_1^N+A_2^N+\dots+A_M^N\right)^{1/N}
    ]
    这个结果的极限是 (A_1) 到 (A_M) 中最大的项（在各项为非负数等适用条件下）。

经典例题：
[
\lim_{n\to\infty}
\left(
\frac{n}{n^2+1}
+\frac{n}{n^2+2}
+\dots+
\frac{n}{n^2+n}
\right)
]

解析：

放缩分母：
[
\frac{n\cdot n}{n^2+n}
\le S_n\le
\frac{n\cdot n}{n^2+1}
]

两端极限均为 1，故：
[
S_n\to1
]

4. 分子有理化

  • 根号与根号相减，必分子有理化。

经典例题：
[
\lim_{x\to+\infty}\left(\sqrt{x^2+x}-x\right)
]

解析：

分子有理化：
[
\sqrt{x^2+x}-x
=\frac{x}{\sqrt{x^2+x}+x}
]

上下同除以 (x)，得：
[
\lim_{x\to+\infty}
\frac{1}{\sqrt{1+\frac1x}+1}
=\frac12
]

5. 通分

  • (0\times\infty) 型化简为 (\frac00) 或 (\frac{\infty}{\infty}) 型。
  • (\infty-\infty) 型变通分，提早通分。

6. 有界量

  • 碰到反三角函数时，要思考利用其有界性。
  • 有界量乘无穷小量 = 无穷小量，即极限为 0。

经典例题：
[
\lim_{x\to0}x^2\sin\frac1x
]

解析：

因为：
[
\left|\sin\frac1x\right|\le1
]

所以 (\sin\frac1x) 为有界量，而 (x^2\to0) 为无穷小量，因此：
[
\lim_{x\to0}x^2\sin\frac1x=0
]

7. 求未知数（双圆梯形已知极限求未知数）

已知极限的情况下，求函数中的两个常量的值。

方法：

  1. 分子有理化或通分。
  2. 提取 (x)（最高次幂）。

经典例题：

已知：
[
\lim_{x\to0}\frac{\sqrt{1+ax^2}-1}{x^2}=b
]

求 (a,b) 的关系。

解析：

分子有理化或利用等价无穷小：
[
\sqrt{1+ax^2}-1\sim\frac12ax^2
]

原式：
[
\lim_{x\to0}\frac{\frac12ax^2}{x^2}
=\frac a2=b
]

故：
[
a=2b
]

8. 幂指代换

  • 无穷的零次方、0 的零次方、1 的无穷次方，都转化为 (1^{YN}) 型，即：
    [
    \lim u(x)^{v(x)}
    =e^{\lim v(x)\ln u(x)}
    ]
    其中需满足相应的定义条件。
  • 指数有未知量时，要进行底数代换。

经典例题：
[
\lim_{x\to0}\left(\frac{\sin x}{x}\right)^{1/x^2}
]

解析：

属于 (1^\infty) 型。原式：
[
\exp\left(
\lim_{x\to0}
\frac{\ln(\sin x/x)}{x^2}
\right)
]

利用泰勒展开：
[
\sin x-x\sim-\frac{x^3}{6}
]

因此：
[
\frac{\sin x}{x}
=1-\frac{x^2}{6}+o(x^2)
]

进而：
[
\ln\frac{\sin x}{x}
\sim-\frac{x^2}{6}
]

指数极限为：
[
-\frac16
]

最终结果：
[
e^{-1/6}
]

9. 两指数相减

遇到两指数相减的情况，提取公因式或进行转化。

10. 提出后一项

遇到多项相加减，提取后一项或最高次项进行化简。

11. 拆分

  • 对于分数类型，拆分分子及拆分时需不需要加 (1-1) 或 (+X-X)，根本判断是拆分能否符合极限的四则运算（极限必须是常数）。
  • 符合条件时积极拆分，尝试加 (1-1) 或加 (X-X)。
  • 对于某一小部分的乘法和除法，要积极使用等价无穷小替换。

12. 其他关键操作与防坑点

  • 多项式同除最高项： (x\to\pm\infty) 时相加减，将所有项同时除以最高次项。
  • 对数函数： 一定要加一减一，构造等价无穷小替换。
  • 换元： 通过换元实现等价无穷小替换。
  • 直接代入： 只要不是 (x\to\infty) 且不在定义域内，(x\to c) 时要大胆代入常数。
  • 防坑点： 尽量不要分数套分数，容易有不可进行等价无穷小替换的情况。用定义域找反例。
  • 递推数列：
    • 证明收敛时，同时证明单调且同侧有界（常用数学归纳法）。
    • 计算极限时，将 (x_n) 和 (x_{n+1}) 的极限都用 (A) 表达，解方程。

经典例题：

已知：
[
x_1=\sqrt2,\qquad x_{n+1}=\sqrt{2+x_n}
]

求极限。

解析：

用数学归纳法证明 (x_n<2)，所以数列有界；再证明数列单调递增。因此数列收敛。

设极限为 (A)，则：
[
A=\sqrt{2+A}
]

两边平方：
[
A^2=A+2
]

解得：
[
A=2\quad\text{或}\quad A=-1
]

由于数列各项为正，故：
[
A=2
]

  • 等价无穷小选择： 对于
    [
    a^x-1\sim x\ln a
    ]
    与
    [
    (1+x)^\alpha-1\sim\alpha x
    ]
    实际要仔细判断用哪一种，有些题中 (\ln) 形式不好化解。

13. 必背工具库

（1）等价无穷小（均为 (x\to0)）

[
\sin x\sim x,\qquad \tan x\sim x
]

[
\arcsin x\sim x,\qquad \arctan x\sim x
]

[
e^x-1\sim x,\qquad \ln(1+x)\sim x
]

[
1-\cos x\sim\frac12x^2
]

[
a^x-1\sim x\ln a
]

[
(1+x)^\alpha-1\sim\alpha x
]

[
\log_a(1+x)\sim\frac{x}{\ln a}
]

[
\tan x-x\sim\frac13x^3
]

[
\tan x-\sin x\sim\frac12x^3
]

[
x-\sin x\sim\frac16x^3
]

（2）重要极限与结论

当 (N\to\infty) 时：

[
N^{1/N}=1
]

[
A^{1/N}=1
]

[
\left(1+\frac1N\right)^N=e
]

极限值：

[
\lim_{x\to+\infty}\frac{x}{a^x}=0
]

[
\lim_{x\to+\infty}\frac{\log_a x}{x}=0
]

级数求和：

[
\frac1{1^2}+\frac1{2^2}+\dots=\frac{\pi^2}{6}
]

裂项相消：

[
\frac1{1\cdot2}+\frac1{2\cdot3}+\dots+\frac1{n(n+1)}=1
]

（3）求导公式

[
(\arctan x)’=\frac1{1+x^2}
]

[
(\tan x)’=1+\tan^2x=\sec^2x=\frac1{\cos^2x}
]

[
(\cot x)’=-\csc^2x
]

且：
[
\cot x=\frac{\cos x}{\sin x}
]

[
(\sin^2x)’=\sin2x=2\sin x\cos x
]

[
(\arccos x)’=-\frac1{\sqrt{1-x^2}}
]

（4）泰勒公式 / 经典例题补充

经典例题：
[
\lim_{x\to0}\frac{\cos x-e^{-x^2/2}}{x^4}
]

解析：

分别展开：

[
\cos x
=1-\frac12x^2+\frac1{24}x^4+o(x^4)
]

[
e^{-x^2/2}
=1-\frac12x^2+\frac18x^4+o(x^4)
]

分子相减：

[
\cos x-e^{-x^2/2}
=\left(\frac1{24}-\frac18\right)x^4+o(x^4)
]

[
=-\frac1{12}x^4+o(x^4)
]

所以极限为：

[
\boxed{-\frac1{12}}
]
