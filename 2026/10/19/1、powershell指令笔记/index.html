Hexo 学习笔记：1、PowerShell 指令

以下命令均是在 Hexo 项目目录中执行的。相对路径 .\ 以当前工作目录为起点。

一、检查 Landscape 主题是否存在

作用

检查指定路径是否存在。

  • 返回 True：路径存在。
  • 返回 False：路径不存在。

命令拆解

  • Test-Path：检查路径是否存在。
  • .\node_modules\hexo-theme-landscape：需要检查的路径。
  • .\：表示从当前工作目录开始查找。

二、复制 Landscape 主题

作用

将 Landscape 主题软件包复制到项目的 themes\landscape 目录。

命令拆解

命令部分 含义
Copy-Item 复制文件或目录
.\node_modules\hexo-theme-landscape 源目录
.\themes\landscape 目标目录
-Recurse 连同子目录及其内容一起复制

这一步是为了让主题文件位于项目自己的主题目录中，便于后续修改。

三、清理旧的生成结果

作用

清理 Hexo 的生成文件及相关缓存，为重新生成做准备。

命令拆解

  • npx：运行项目中可用的软件包命令。
  • hexo：调用 Hexo 命令行工具。
  • clean：清理生成结果和相关缓存。

七、检查分类页面是否生成

作用

十二、核心区别

命令 主要作用
Test-Path 检查路径是否存在
Copy-Item 复制文件或目录
npx hexo clean 清理旧的生成结果
npx hexo generate 生成网页文件
npx hexo server 启动本地预览服务器
Ctrl + C 中断当前终端运行的服务器进程
npx hexo deploy 发布生成的网站文件

记住：修改源文件 → 生成网页文件 → 发布网站 是三个不同环节。server 用于本地预览，不等于部署线上网站。

  • py –version 表示检查目前python的版本。

  • Get-ChildItem 获取当前文件夹里面的文件和子文件夹。

  • Get-ChildItem -Force 这里的 -Force 是让 PowerShell 连隐藏文件和隐藏文件夹也一起显示出来，例如 Git 使用的 .git 文件夹。

  • New-Item -ItemType Directory -Name backend

  • New-Item：创建一个新项目。

  • -ItemType Directory：指定创建的是文件夹。

  • -Name backend：将文件夹命名为 backend。

  • mkdir backend mkdir：Make Directory 的缩写，意思是创建目录。backend：新文件夹的名称。

  • cd backend - cd：Change Directory 的缩写，意思是切换目录。- backend：指定要进入的文件夹。切换的是powershell所属的地方。

  • New-Item main.py 创建一个叫做main.py的文件。

  • Get-ChildItem 这条命令会列出 backend 文件夹中的内容。
