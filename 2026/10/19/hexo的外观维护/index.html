Hexo 学习笔记：主题、首页改造与文章分类

一、Hexo 主题的基本概念

1. 什么是主题（Theme）？

主题是一整套决定博客外观和页面布局的文件，可以控制：

  • 首页如何排列内容
  • 页面使用什么颜色和字体
  • 导航栏如何展示
  • 文章页面如何布局
  • 页面样式与部分交互效果

主题可以理解为博客的“装修方案”。

2. 什么是 Landscape？

Landscape 是 Hexo 的一个具体主题，也是 Hexo 默认提供的主题之一。

它属于简洁、传统的博客类主题，原本主要用于展示博客文章，具有文章列表、侧边栏、分类和归档等典型功能。

“主题”是总概念，“Landscape”是具体的主题，就像“壁纸”是总概念，而“自然风景壁纸”是其中一种。

3. node_modules 与 themes 的区别

  • node_modules：通常存放通过 npm 安装的软件包及其依赖。
  • themes：Hexo 项目中用于存放主题文件夹的目录。
  • themes/landscape：项目中 Landscape 主题的文件目录。

我们发现 themes 中没有 landscape 文件夹，但 node_modules 中已经存在 Landscape 主题软件包，于是将它复制到 themes/landscape，以便修改主题文件。

二、修改首页模板

1. 首页模板的位置

文件路径：

themes/landscape/layout/index.ejs

各部分含义：

  • themes/landscape：Landscape 主题目录。
  • layout：存放页面布局模板的文件夹。
  • index.ejs：负责首页的模板文件。

layout 的英文意思是“布局”。在 Hexo 主题中，它用于存放网页布局模板。

.ejs 是 EJS 模板文件的扩展名。EJS 允许在模板中嵌入特定语法，以便生成网页内容。

三、修改首页样式

1. 样式文件的位置

themes/landscape/source/css/style.styl

各部分含义：

  • source：主题的源文件目录。
  • css：存放样式相关文件的目录。
  • style.styl：存放 Stylus 样式代码的文件。

Stylus 是一种 CSS 预处理器。我们使用 Stylus 编写样式，再由 Hexo 生成浏览器可以使用的 CSS 文件。

2. 实际进行的修改

我们在 style.styl 文件末尾添加首页相关样式，包括：

  • .knowledge-home：控制知识空间区域的样式。
  • .knowledge-grid：控制知识分类卡片的网格布局。
  • 卡片样式：控制卡片的间距和外观。

布局根据屏幕宽度调整：

屏幕情况 卡片排列
较宽屏幕 三列
中等宽度屏幕 两列
较窄屏幕 一列

这种根据屏幕宽度调整页面布局的设计叫作响应式设计。

3. HTML 与 CSS 的分工

  • HTML：组织网页内容结构。
  • CSS：控制网页的视觉呈现。
  • Stylus：编写样式的工具，其代码会生成 CSS。

因此，修改首页模板和样式文件是两个不同的工作。

四、源文件、生成文件与线上网站

1. 源文件

我们实际修改的文件包括：

  • themes/landscape/layout/index.ejs
  • themes/landscape/source/css/style.styl
  • source/_posts/我的第一篇博客.md

这些文件用于保存模板、样式和文章内容。

2. public 文件夹

public 用于存放 Hexo 生成的网页文件。

例如：

  • public/index.html：生成后的首页 HTML。
  • public/css/style.css：生成后的 CSS 样式文件。
  • public/categories/Hexo笔记/index.html：生成后的分类页面。

可以把源文件理解为制作网页的材料，把 public 中的文件理解为加工后的成品。

通常应该修改源文件，而不是直接修改 public 中的生成文件，因为重新生成时，public 中的内容会被重新生成，直接修改的内容可能丢失。

3. 检查生成结果

我们曾经检查：

  • public/index.html 是否包含“我的知识空间”和知识分类入口。
  • public/css/style.css 是否包含 .knowledge-home、.knowledge-grid 等样式。

这样可以确认源文件的修改是否已经反映到生成结果中。

如果生成文件已经更新但线上网站仍显示旧内容，还需要进一步检查发布过程或浏览器缓存等因素，不能直接认定是某一个原因。

访问地址为：

这里的 localhost:4000 是本地预览地址，只能用于访问正在运行的本地服务器，不是公开网站地址。

七、本地预览、生成与部署的区别

本地预览

使用 Hexo 本地服务器查看网页效果。我们检查过分类页面，并确认文章能够显示。

生成

Hexo 根据源文件生成网页文件，并将生成结果放入 public。

部署

将生成后的网站文件发布到配置好的线上托管位置。

这三个环节不能混为一谈：本地能够访问，不代表线上网站已经更新。
