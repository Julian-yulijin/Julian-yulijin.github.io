1.2 认识项目目录

创建项目后，主要会接触以下目录和文件。

source/_posts/

存放博客文章。使用 Hexo 创建的新文章通常会保存在这里。

_config.yml

项目根目录下的主要配置文件，可以修改网站标题、副标题等设置。

node_modules/

存放项目使用的依赖软件包。一般不需要手动修改里面的文件。

themes/

存放网站主题相关文件，用于控制博客的外观和布局。

四、生成并预览网站

Hexo 有几个常用命令。

4.1 清理旧的生成文件

逐部分解析：

部分 含义
npx 运行 npm 软件包提供的命令行程序。
hexo 指定 Hexo 程序。
clean Hexo 子命令，用于清理之前生成的网站文件。

为什么需要清理？ 当旧的生成文件可能影响预览时，可以清理后重新生成。它不会替你删除文章源文件，也不等于删除整个项目。

4.2 重新生成网站

逐部分解析：

这一步会把文章和网站配置转换为浏览器能够访问的网页文件。

4.5 为什么修改后网页有时没有变化？

常见原因包括：

  • 修改后没有保存文件。
  • 网站还没有重新生成。
  • 浏览器显示的是缓存内容。
  • 服务器仍在运行，或者预览的不是预期的项目。

可以按下面的顺序检查：

  1. 在 VS Code 中按 Ctrl + S 保存。
  2. 在终端执行 npx hexo clean。
  3. 执行 npx hexo generate。
  4. 执行 npx hexo deploy。
  5. 在浏览器打开终端显示的本地地址并刷新，同时反复执行2-4步。

不需要每次修改文章都机械地执行全部步骤；理解每条命令的作用后，可以按实际情况选择。
